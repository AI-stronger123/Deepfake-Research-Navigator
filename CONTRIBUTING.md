# Contributing to Awesome Deepfake Research

Thank you for helping maintain a reliable research resource.

## Add a paper

1. Confirm the paper exists via an official publisher, conference, or preprint page.
2. Select **one primary category** and add relevant optional method and modality tags.
3. Include publication year, venue/status (e.g., *arXiv preprint* rather than implying acceptance), paper URL, and official code URL when available.
4. Write a factual one-sentence contribution without unsupported comparative claims.
5. Check for duplicates and sort newest first.

## Add a dataset

Provide the original paper, official download/project link, supported modalities, tasks, sample scale, real/fake sources where disclosed, annotation type, access terms, and license when known. Never infer missing metadata.

## Add a benchmark result

Link the original result and report dataset version, split/protocol, metric, and any restrictions. Do not merge scores from incompatible protocols into one ranking.

## Editorial principles

- Cite original sources wherever possible.
- Distinguish peer-reviewed publications from preprints.
- Do not fabricate code links, publication venues, benchmark results, or release dates.
- Use neutral, research-focused descriptions.
- Prefer sustainable, documented open-source projects and official datasets.
- Report broken links, corrections, and suspected issues via GitHub Issues.

## Submission

Open a pull request describing the addition or correction and link relevant sources. Maintainers may reclassify entries to preserve taxonomy consistency.
